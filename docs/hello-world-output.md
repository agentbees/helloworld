# Expected Hello World output

When the Hello World page loads successfully in a supported modern browser, it
displays the exact visible message:

> Hello, World!

## Verify the result

1. Start the application with `npm start`.
2. Open <http://localhost:3000/> in a supported modern browser.
3. Confirm that the page loads and that `Hello, World!` is visible.

Seeing that exact message confirms that the application loaded successfully.
If the page cannot be opened or the message is missing or different, the
expected result has not been reached.
